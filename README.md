# Arabic Study

Gulf/Saudi Arabic verbs with the Fusha (MSA) equivalent beside each form.
Next.js 15 (App Router), statically generated. Data lives in `lib/verbs.json`.

```bash
npm install
npm run dev
```

Pages: home, `/verbs/[go|see|make|read]` (Gulf / Fusha toggle, past/present/future/command), `/flashcards`.
Pronunciation uses the browser Web Speech API (`ar-SA`).
